### [Minimap Fixed and Improved](https://www.nexusmods.com/warhammer40kdarktide/mods/633)
<img width="1689" height="476" alt="image" src="https://github.com/user-attachments/assets/1e5fcc37-66cf-463c-bf92-b1b7dfe93dd8" />

Customizable minimap tracking teammates and objectives. Compatible with Strike Map.

<details>
<summary><b>Mod Settings / Commands</b></summary>

**General**

*Style Settings*
- Horizontal alignment [Center, Left, Right]
- Vertical alignment [Center, Top, Bottom]
- X/Y Offset
- Background Color
- Background Opacity

*Minimap Visibility*
- Show in Hub
- Show in Shooting Range/Psykhanium
- Show When Dead

**Icons & Markers**

*Class Icon Settings*
- Display Class Icon

*Icon Visibility*
- Attention Pings
- Location Pings
- Threat Area Pings
- Threat Units
- Companion Target Skull
- Players
- Mission Objectives
- Tagged Interactions
- Disabled Teammates [Show as normal (no status icons), Non-glowing icons (colored), Non-glowing icons with rings, Glowing icons with rings, Glowing icons without rings]
- Hide bots
- Teammate Facing Arrows

*Distance Markers*
- Show Distance on Players / Dogs/Companions / Enemies / Objectives / Interactables / Pings
- Only Show Distance When Out of Range

*Vertical Distance Symbols*
- Show Vertical Symbols (↑/↓)
- Vertical Distance Threshold (meters)
- Vertical Distance Transparency (0-255)
- Vertical Arrow Size
- Vertical Arrow Color
- Arrow Color (Alpha / Opacity)

*Display Names*
- Show Player Names
- Show Dog/Companion Names

*Dog Settings*
- Dog Icon Style [Dog whistle, Class Icon, Unicode Icon]
- Show Your Own Dog
- Show Teammates' Dogs

**Enemy Radar**

*Radar Settings*
- Enable Enemy Radar
- Scan Range (meters)
- Priority Mode [Threat (Type + Health), Distance (3D)]
- Only Show Names If Pinged

*Melee Range Ring*
- Show Melee Range Ring
- Melee Range (meters)
- Melee Ring Color
- Melee Ring Opacity

*Vertical Distance Transparency*
- Enable Vertical Distance Transparency
- Vertical Distance Threshold (meters)
- Transparency Alpha (0-255)

*Enemy Grouping (Clustering)*
- Enable Enemy Grouping
- Grouping Radius (meters)
- Minimum Group Size
- Show Enemy Type Text

*Enemy Categories (each has Enable on Radar, Color, Radar Limit (0 = Unlimited), Show Name on Radar)*
- Human Bosses (Captains, Twins)
- Monsters (Plague Ogryn, Chaos Spawn, Daemonhost)
- Disablers (Hounds, Mutants, Trappers)
- Ranged Specials (Snipers, Flamers, Bombers)
- Poxbursters
- Ranged Elites (Gunners, Shotgunners, Reapers)
- Crushers & Maulers
- Melee Elites (Ragers, Bulwarks)
- Shooters (Dreg Stalker, Scab Shooter, Scab Stalker)
- Chaff (Hordes, Roamers, Groaners, Poxwalkers)

*Specific Enemy Colors (Specials & Elites)*
- Override Specific Enemy Coloring
- Colors for Hound, Trapper, Mutant, Sniper, Flamer (Scab & Dreg), Bomber (Scab & Dreg), Poxburster, Crusher, Mauler, Gunner (Scab & Dreg), Plasma Gunner, Reaper, Shotgunner (Scab & Dreg), Rager (Scab & Dreg), Bulwark

**Strike Map**

*Strike Map Dimensions*
- Height
- Half Height
- Depth / Z-Offset

*Line Thicknesses*
- Contours (Walls & Ledges)
- Stairs (Stair Ticks)
- Slopes (Incline Ink)

*Floor Colors & Opacities*
- Floor Above (Color, Opacity)
- Current Floor (Color, Opacity)
- Floor Below (Color, Opacity)

**Commands:**
- `/minimap_debug` - Toggle minimap scan diagnostic logging
